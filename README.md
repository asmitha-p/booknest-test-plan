For this Week 1 task, I created a complete test plan and test case document for a hypothetical online bookstore web application called BookNest. The report is a single Word document of approximately 28 pages. It begins with research on industry best practices, drawing on standards and guidance such as ISO/IEC/IEEE 29119, IEEE 829, ISTQB, OWASP and WCAG. The test plan then covers the introduction, scope and objectives, requirements analysis with traceability, risk assessment, test strategy, test environment, resources and roles, schedule, and deliverables. The risk assessment rates product and project risks by likelihood and impact and links each one to a mitigation. The strategy section defines test levels, techniques, the automation approach, defect severity levels, entry and exit criteria, and suspension and resumption criteria.
The second part contains 23 detailed test cases: 13 functional, 5 usability and accessibility, and 5 security cases. Each case includes an ID, priority, linked requirement, design technique, preconditions, test data, numbered steps, expected results, and clear pass and fail criteria. They cover registration, login and account lockout, password reset, search, cart, checkout and payments, responsive design, keyboard accessibility, SQL injection, cross-site scripting, session handling, and access control. Through this task I learned how to apply risk-based testing, boundary value analysis and equivalence partitioning, and how to keep requirements and tests traceable so the quality of a release can be judged with evidence.
